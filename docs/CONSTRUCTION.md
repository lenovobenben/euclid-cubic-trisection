# 尺规宏与代码步骤对应

## 1. 长度转移与塌圆规

代码的 `circle(name, center, radius_start, radius_end)` 表示以指定点为圆心、给定线段长度为半径作圆。任意位置的线段转移由《几何原本》I.2 实现。

给定非零线段 $AB$ 和新起点 $P$。若 $P=A$ 或 $P=B$，直接画圆即可。其余情况按以下步骤进行。

1. 在 $AP$ 上用两个圆构造等边三角形 $DAP$，任选一个顶点 $D$。
2. 作以 $A$ 为圆心、过 $B$ 的圆。它在从 $D$ 经过 $A$ 的射线上、越过 $A$ 的交点记为 $E$。
3. 作以 $D$ 为圆心、过 $E$ 的圆。它在从 $D$ 经过 $P$ 的射线上、越过 $P$ 的交点记为 $F$。
4. 因 $DA=DP$ 且 $DE=DF$，有 $PF=AE=AB$。以 $P$ 为圆心、过 $F$ 画圆。

每次直接画圆都采用已有圆心和已有过圆点。选择越过端点的交点由直线次序关系完成。[Euclid I.2](https://mathcs.clarku.edu/~djoyce/java/elements/bookI/propI2.html)

## 2. 中点

对不同点 $A,B$，分别作以 $A,B$ 为圆心、过另一点的圆，取交点 $U,V$。连接 $UV$ 与 $AB$，交点即中点。

两个圆的半径均为 $AB$，因此有两个不同交点，$UV$ 为垂直平分线。主流程四次中点的端点均不同。

## 3. 过点作垂线

若点 $P$ 在线 $l$ 上，以 $P$ 为圆心、单位长度为半径画圆，与 $l$ 交于 $S,T$。作 $ST$ 的垂直平分线，得到所求垂线。

若 $P$ 在线外，在线上取一个已有点 $R$。作以 $P$ 为圆心、$2PR$ 为半径的圆，与 $l$ 交于 $S,T$。半径严格大于 $P$ 到 $l$ 的距离，所以有两个不同交点。$PS=PT$，故 $ST$ 的垂直平分线经过 $P$，且垂直于 $l$。加倍长度用上一节的线段转移及延长实现。

上述构造均有固定有限步数。程序中 `Line.perpendicular` 精确重放所得直线。

## 4. 过点作平行线

先过点 $P$ 作参考线 $l$ 的垂线 $m$，再过 $P$ 作 $m$ 的垂线，得到所求平行线。主流程中的参考线始终有定义。

## 5. 角的复制

在相同半径的圆上，相同弦长对应相同的小圆心角。主构造在单位圆上先复制 $MN$，再复制 $XQ$。每次以目标起始点为圆心作弦长圆，并取与目标单位圆的交点。

输入锐角和目标三分之一角均介于 $0$ 与 $\pi$，上半平面或原角内部的选择确定复制方向。完整存在性和唯一性见 [PROOF](PROOF.md)。

## 6. 操作名称对应

| 作图对象 | 代码名称 | 取得方式 |
|---|---|---|
| 原点、正轴单位点 | `O, X, Y` | 输入标定 |
| 原角顶点及边上标记 | `V, A, B` | 输入 |
| 两个单位圆 | `unit_O, unit_V` | 单位长度画圆 |
| 原角的单位圆端点 | `M, N` | 直线圆求交及射线选点 |
| 原角在坐标原点的复制 | `P` | 等弦复制，上半平面选点 |
| 余弦投影及长度转移 | `C, D` | 垂线、圆与轴求交 |
| 截距点 | `D_half, E` | 两次中点 |
| 参考斜率 | `Y_half, H, W, reference` | 中点、平行线、垂线和连线 |
| 目标直线 | `L` | 过 `E` 作 `reference` 的平行线 |
| 正根交点 | `K` | 一次立方曲线求交及正半平面选点 |
| 根的投影及单位圆提升 | `F, Q` | 垂线与轴、圆求交 |
| 最终两条射线上点 | `R1, R2` | 两次等弦复制 |

`k0,k1,k2` 等带数字的点名保存求交的全部候选点。`select` 保存候选点中的一个已有点及其语义名称。`steps` 中每个输入对象均已在前面的步骤或初始输入中出现。

当前固定程序共记录 39 个步骤，包含几何动作和选点。

| 操作 | 次数 |
|---|---|
| 两点连线 | 5 |
| 以给定线段长度画圆 | 6 |
| 中点 | 4 |
| 平行线 | 2 |
| 垂线 | 3 |
| 直线与直线求交 | 3 |
| 直线与圆求交 | 4 |
| 圆与圆求交 | 3 |
| 直线与给定立方曲线求交 | 1 |
| 唯一候选点选择 | 8 |

两条给定轴已经存在。角两边的支撑直线在程序中显式记录，实物作图时可复用给定边。长度转移、中点和平行垂线的辅助图形展开见上文，基础画线画圆总数需按选定宏另行统计。本表由 [精确案例](../experiments/results/example.json) 的实际记录产生。
