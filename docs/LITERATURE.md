# 题源、经典依据与贡献范围

## 1. 直接题源

本项目对应《Euclid 十题研究路线图》第 6 项，项目名为 `euclid-cubic-trisection`。路线图保存在同系列圆锥曲线判定项目的 `docs/Euclid十题研究路线图.md`。

原题来自 `lenovobenben/ai-math-notes` 的“尺规作图三等分角”问答，对话 ID 为 `6959b46c-77e4-8327-9eb6-3b1afb37239b`。读取的本地题集提交为 `50cccad292a296087770a377080dcde9ef40657b`。原问答字节级快照保存在项目 `sources/` 中。[原始问答](../sources/original_trisection_qa.md) · [题集仓库](https://github.com/lenovobenben/ai-math-notes)

用户在原始问答中提出给定坐标系及 $y=x^3$ 图像、对锐角三等分的题目。原回答给出余弦三倍角转化路线。项目按用户指定的系列路线开展具体实现、证明与核验。

## 2. 原回答的订正与补充

原回答的核心方程 $4t^3-3t=\cos\theta$ 正确。正式版本补齐以下部分。

- 参考斜率的作法明确为连接 $O=(0,0)$ 与 $W=(1,3/4)$。原回答若将正 $x$ 轴上的 $(4,0)$ 与正 $y$ 轴上的 $(0,3)$ 相连，实际斜率为 $-3/4$。
- 在全部锐角输入下，三次方程恰有三个不同实根。其区间分别为 $(-1,-1/2)$、$(-1/2,0)$、$(\sqrt3/2,1)$。
- 第一象限交点在整个输入域中始终唯一，正式规则采用精确半平面测试。
- 原回答最后给出一个三分之一角，本项目明确输出原角内部的两条射线，并证明第二次等弦复制的交点选择。
- 角的原始位置、顺时针排列、标记长度、输入与中间对象重合等情况均有统一处理。

原回答备注中的正切路线未展开为本项目主构造。这里完成的流程沿用余弦路线。[完整作法](ANSWER.md) · [一般证明](PROOF.md)

## 3. 经典依据

余弦三倍角恒等式、单位圆上的等弦等圆心角、实三次多项式的次数约束和连续函数介值性质，构成正确性证明的基础。

任意位置的长度转移依据《几何原本》I.2，允许在塌圆规语义下实现线段半径宏。[Euclid I.2](https://mathcs.clarku.edu/~djoyce/java/elements/bookI/propI2.html)

角三等分、三次方程及尺规可构造数的关系有经典教材讨论。路线图列出以下材料供后续历史与文献比较。本阶段保留这些文献入口，其具体页码、固定曲线作法与历史首创归属仍待逐页核对。[Courant–Robbins 相关教材节选](https://www.math.utah.edu/~howe/2021-spring/6320/handouts/courant-robbins-constructible.pdf) · [ERIC ED100648](https://files.eric.ed.gov/fulltext/ED100648.pdf)

## 4. 本阶段成果

本阶段整理一套覆盖全部锐角的有限构造，明确一次给定立方曲线求交的能力，给出三个根的统一隔离与正根选择规则，将结果转回原角的两条射线，并提供一般证明、精确几何重放、独立角核验及可复现证书。

项目沿用系列上一题的中文研究文档、中英文 README、SageMath 10.7 精确运算和来源保存方式。第二阶段将单独制作动画。[Euclid-Conic-Classification](https://github.com/lenovobenben/euclid-conic-classification)

数学中使用的恒等式和经典尺规宏按其既有来源记录。历史文献比较完成后可进一步细化该具体实现与既有作法的关系。
