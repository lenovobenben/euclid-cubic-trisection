# 特殊情形与覆盖范围

## 1. 分支总览

| 输入或中间情形 | 处理与结论 |
|---|---|
| 原角顺时针排列 | 以两个有向侧别条件选原角内部的 $R_1$ |
| 原角逆时针排列 | 同一内部选点规则 |
| 原顶点与坐标原点重合 | 两个单位圆可共用，后续求交均合法 |
| 原顶点与单位点重合 | 原图与坐标辅助对象允许坐标重合 |
| 原边水平或竖直 | 射线圆求交照常进行 |
| 边上标记极近顶点 | 按射线方向取得单位点，长度无下限 |
| $\theta$ 接近 $0$ | $c$ 接近 $1$，各严格不等式继续成立 |
| $\theta$ 接近 $\pi/2$ | $c$ 接近 $0$，截距及长度转移半径仍为正 |
| 三次方程有三个实交点 | 取唯一横坐标为正的交点 |
| 三等分角本来可尺规作出 | 统一主流程仍然成立 |
| 第二次小弦复制返回已有点 $M$ | 排除 $M$，取另一交点 $R_2$ |

根的完整位置为 $(-1,-1/2)$、$(-1/2,0)$、$(\sqrt3/2,1)$，在整个锐角输入域中都固定成立。[PROOF](PROOF.md)

## 2. 精确案例族

正式核验采用十二个角参数族，每族在四种位置与方向下执行，总计 48 次完整作图。

| 参数族 | 选择理由 |
|---|---|
| $\theta=60^\circ$ | 输出余弦的最小多项式次数为 $3$ |
| $\theta=45^\circ$ | 输出 $15^\circ$，覆盖代数余弦输入 |
| $\theta=30^\circ$ | 输出 $10^\circ$，覆盖另一代数输入 |
| $c=3/5,4/5,5/13$ | 多组有理余弦与非对称方向 |
| $c=7/128$ | 已知目标根 $t=7/8$ 的独立对照 |
| $c=3\sqrt{15}/16$ | 已知目标根 $t=\sqrt{15}/4$ 的独立对照 |
| $c=10^{-30}$ | 接近直角的合法输入 |
| $c=1-10^{-30}$ | 接近零角的合法输入 |
| $c=10^{-100}$ | 极近直角，回归代数数求交比较与证书编码 |
| $c=1-10^{-100}$ | 极近零角，回归数域精度与相近根隔离 |

四种位置分别采用标准逆时针角、平移旋转逆时针角、平移旋转顺时针角、含 $10^{-30}$ 级射线标记的顺时针角。射线标记还采用不同的正比例长度，检查角大小与标记距离无关。[案例定义](../experiments/fixtures.py)

## 3. 首版范围外输入

命令行和函数接口要求严格锐角。退化射线、相同射线、反向射线、直角及钝角会得到明确的输入错误。核验覆盖九种非法输入。

这是首版输入域的程序约定。若进一步扩展到直角、钝角或零角，应同时更新题面、取根规则及方向选择证明。

## 4. 边界为什么需要另行定义

若 $\theta=0$，则 $c=1$，方程分解为 $(t-1)(2t+1)^2=0$，出现重根，输出射线也重合。

若 $\theta=\pi/2$，则 $c=0$，方程为 $t(4t^2-3)=0$，截距点与原点重合，转移余弦的圆退化。目标三等分角可单独构造为 $30^\circ$，首版接口按输入域拒绝该边界。

当 $\theta$ 为钝角时，余弦为负，原先的正长度转移和唯一正根规则需要调整。全锐角版本的证明已由独立章节完成。
